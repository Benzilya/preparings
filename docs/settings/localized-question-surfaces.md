# Localized question surfaces

## English

Question details, the category index, and category detail pages now consume the shared typed interface dictionary. The selected browser-local setting controls navigation labels, section headings, counts, and links without duplicating domain question content.

The validated question data remains language-neutral source content. Only product interface chrome is translated. Static route generation and deterministic category sorting remain unchanged.

## Русский

Страница вопроса, каталог категорий и страницы отдельных категорий теперь используют общий типизированный словарь интерфейса. Выбранная локальная настройка языка управляет навигационными подписями, заголовками секций, счётчиками и ссылками без дублирования доменного контента вопросов.

Валидированные данные вопросов остаются исходным контентом без автоматического перевода. Локализуется только интерфейс продукта. Статическая генерация маршрутов и детерминированная сортировка категорий не изменены.
