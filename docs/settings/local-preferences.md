# Local Preferences / Локальные настройки

## English

Release 1.0 stores interface preferences in the browser under the versioned key `qa-interview-trainer:settings:v1`.

The Settings page supports interface language, catalog density, explanation visibility, preference reset, and confirmed deletion of local question progress. Settings and progress use separate storage keys, so resetting preferences does not remove progress.

## Русский

Release 1.0 хранит настройки интерфейса в браузере под версионированным ключом `qa-interview-trainer:settings:v1`.

Страница Settings поддерживает выбор языка интерфейса, плотности каталога, видимости пояснений, сброс настроек и подтверждаемое удаление локального прогресса вопросов. Настройки и прогресс используют разные ключи, поэтому сброс параметров не удаляет прогресс.
