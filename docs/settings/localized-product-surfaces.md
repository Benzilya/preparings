# Localized product surfaces / Локализованные продуктовые экраны

## English

Dashboard, Progress, Favorites, and Question Library now consume one typed interface dictionary selected through the existing local settings adapter.

The language choice is restored from `qa-interview-trainer:settings:v1` and applied without duplicating domain data. Question titles, explanations, categories, and sources remain canonical content; only interface labels, actions, statuses, messages, date formatting, and accessibility labels are localized.

Covered surfaces:

- application shell and navigation;
- Dashboard and its progress summary;
- Question Library filters and empty states;
- Favorites page and progress status labels;
- Progress analytics, import/export, reset confirmation, activity history, dates, and notifications.

## Русский

Dashboard, Progress, Favorites и Question Library теперь используют единый типизированный словарь интерфейса, выбранный через существующий адаптер локальных настроек.

Язык восстанавливается из `qa-interview-trainer:settings:v1` и применяется без дублирования доменных данных. Заголовки вопросов, пояснения, категории и источники остаются каноническим контентом; локализуются только подписи интерфейса, действия, статусы, сообщения, форматирование дат и accessibility-метки.

Покрытые экраны:

- каркас приложения и навигация;
- Dashboard и сводка прогресса;
- фильтры и пустые состояния Question Library;
- страница Favorites и подписи статусов;
- аналитика Progress, импорт/экспорт, подтверждение сброса, история активности, даты и уведомления.
