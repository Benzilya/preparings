# Release 1.0 Scope / Объём релиза 1.0

## English

Release 1.0 delivers a complete non-AI interview preparation product. AI-assisted interviewing is intentionally deferred to Release 2.0 so the first release can focus on reliable learning workflows, validated content, progress tracking, and a polished user experience.

### Included

- validated question library with search, filters, categories, levels, tags, and sources;
- detailed question pages with expected answers, examples, common mistakes, follow-up questions, and related topics;
- bookmarks and learning progress;
- recent activity, weak-topic discovery, and completion statistics;
- responsive dashboard, light and dark themes, accessibility, empty states, loading states, and error states;
- import and export of local progress;
- bilingual English and Russian documentation;
- automated architecture, type, lint, format, build, and test checks.

### Deferred to Release 2.0

- AI interviewer;
- adaptive question generation;
- automated answer scoring and feedback;
- LLM-based study recommendations;
- provider integrations and usage billing.

### Release criteria

Release 1.0 is ready when all planned non-AI routes are functional, seeded content passes runtime validation, user progress persists, core flows have automated tests, and the production build passes CI.

## Русский

Релиз 1.0 представляет собой полноценный продукт для подготовки к собеседованиям без AI. AI-интервью намеренно перенесено в Release 2.0, чтобы первый релиз был сосредоточен на надёжных учебных сценариях, валидированном контенте, отслеживании прогресса и завершённом пользовательском опыте.

### Входит в релиз

- валидируемая база вопросов с поиском, фильтрами, категориями, уровнями, тегами и источниками;
- подробные страницы вопросов с ожидаемыми ответами, примерами, типичными ошибками, уточняющими вопросами и связанными темами;
- закладки и учебный прогресс;
- недавняя активность, определение слабых тем и статистика прохождения;
- адаптивный дашборд, светлая и тёмная темы, доступность, пустые состояния, состояния загрузки и ошибок;
- импорт и экспорт локального прогресса;
- двуязычная документация на английском и русском;
- автоматические проверки архитектуры, типов, линтинга, форматирования, сборки и тестов.

### Перенесено в Release 2.0

- AI-интервьюер;
- адаптивная генерация вопросов;
- автоматическая оценка ответов и обратная связь;
- рекомендации по обучению на базе LLM;
- интеграции с AI-провайдерами и биллинг использования.

### Критерии готовности

Release 1.0 готов, когда все запланированные маршруты без AI работают, стартовый контент проходит runtime-валидацию, прогресс пользователя сохраняется, основные сценарии покрыты автоматическими тестами, а production-сборка успешно проходит CI.
