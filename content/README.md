# Educational Content / Образовательный контент

## EN

Educational materials are stored outside the application UI. This directory will contain versioned Markdown, MDX, or validated JSON for questions, topics, company collections, and practice cases.

Content must cite sources, distinguish theory from personal experience, and never invent practical experience.

## RU

Учебные материалы хранятся отдельно от интерфейса приложения. В этой директории будут находиться версионируемые Markdown, MDX или валидированный JSON для вопросов, тем, подборок компаний и практических кейсов.

Контент должен содержать источники, отделять теорию от личного опыта и никогда не выдумывать практический опыт.
